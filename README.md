# Озвучка манхвы (Android)

Плавающая кнопка поверх браузера (например Opera в полноэкранном режиме).
Нажали ▶ — приложение делает снимок экрана, распознаёт русский текст в пузырях,
читает его вслух и само листает страницу вниз. Всё работает на телефоне, без интернета.

**Требуется Android 11 или новее.**

## Как получить APK без компьютера (через GitHub)

1. Зарегистрируйтесь на github.com (бесплатно).
2. Создайте новый репозиторий (кнопка «New»), например `manhwa-voice`, тип Public или Private.
3. Загрузите в него все файлы из этого архива, сохранив папки
   (на компьютере: «Add file → Upload files» и перетащить содержимое папки ManhwaVoice).
   Важно, чтобы загрузилась скрытая папка `.github/workflows`.
4. Откройте вкладку **Actions** — сборка запустится сама (около 5–8 минут).
5. Когда появится зелёная галочка, откройте **Releases** (справа на главной странице репозитория)
   и скачайте `ManhwaVoice.apk` прямо на телефон.

## Как собрать в Android Studio

1. Скачайте модель русского языка
   https://github.com/tesseract-ocr/tessdata_best/raw/main/rus.traineddata
   и положите её в `app/src/main/assets/tessdata/rus.traineddata`.
2. Откройте папку проекта в Android Studio и нажмите Run (или Build → Build APK).

## Установка и включение

1. Откройте скачанный APK, разрешите установку из этого источника.
2. Запустите «Озвучка манхвы» → «Открыть настройки спецвозможностей» → включите службу.
3. **Android 13+:** если пишет «Настройка ограничена» — Настройки → Приложения → «Озвучка манхвы»
   → ⋮ → «Разрешить ограниченные настройки», затем снова включите службу.
4. Проверьте голос кнопкой «Проверить голос». Если русского голоса нет — «Скачать русский голос»
   (в Google Speech Services голоса бесплатные).

## Управление

- **Нажатие** на круглую кнопку — старт / пауза.
- **Перетаскивание** — переместить кнопку.
- **Долгое нажатие** — забыть прочитанное (текущий экран прочитается заново).
- Значки: ▶ ожидание, ⋯ распознаёт или листает, ❚❚ читает вслух.
- В конце страницы звучит «Конец главы». Переходите к следующей и снова жмёте ▶.
- Если выйти из браузера, чтение само встаёт на паузу.

В настройках можно поменять скорость речи, шаг прокрутки и паузы. На экране «Выбор голоса»:

- **Голос телефона** — движок синтеза речи, русские голоса (с прослушиванием), высота голоса.
  Больше голосов без интернета даёт бесплатный движок RHVoice из Google Play.
- **Fish Audio** — нейросетевые голоса. Скопируйте свой API-ключ и нажмите «Вставить»
  (ключ хранится только на телефоне, в приложение и на GitHub он не попадает).
  Встроенный каталог голосов с fish.audio: русские голоса, популярные / часто слушают / новые,
  поиск, образцы звучания, выбор в одно касание и список недавних.

Приложение само проверяет обновления при запуске и предлагает установить новую версию поверх старой.

## Как это устроено

- `ReaderService.kt`: служба спецвозможностей. Кнопка поверх экрана, снимок экрана
  (`takeScreenshot`), прокрутка свайпом (`dispatchGesture`), озвучка по порядку.
- `ScreenText.kt`: путь от снимка до реплик (без зависимостей от Android):
  1. пузыри ищутся как светлые области в контуре (`BubbleFinder.kt`), каждый вырезается
     **без контура, хвостика и рисунка вокруг** и читается точной моделью Tesseract;
  2. остальной экран просматривается быстрой моделью — только чтобы найти, где текст;
  3. найденный текст вне пузырей перечитывается точной моделью по маленькой вырезке;
  4. тёмные буквы с белой обводкой — отдельной обработкой (`OutlineFix.kt`).
- `TextLayout.kt`: сборка реплики из слов, склейка переносов, проверка слов по словарю
  (`Lexicon.kt`: исправление ошибок в 1–2 буквы, разделение слипшихся слов, отсев мусора),
  перевод КАПСА в обычный регистр, память прочитанного (дочитывает продолжение реплики,
  обрезанной краем экрана; повтор фразы через несколько экранов читает снова).
- `OcrEngine.kt`: два экземпляра Tesseract (точная и быстрая модели) в двух потоках.
- `MainActivity.kt`: экран настроек; `Updater.kt`: обновление из GitHub Releases;
  `FishTts.kt`: озвучка через Fish Audio.

Словарь `app/src/main/assets/ru_words.tsv.gz` — 300 тысяч самых частых русских словоформ
из проекта [wordfreq](https://github.com/rspeer/wordfreq) (данные под лицензией CC BY-SA 4.0).
